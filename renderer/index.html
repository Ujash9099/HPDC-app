Guide
{{ appName }} · {{ appVersion }}
Getting started
Set part geometry, material and process inputs in the header and side panels. Results — shot curve, process window, locking force, fill time and defect risk — update live as you type.
Save, Save As & Open
Save and Save As (top bar) write your current project's inputs to a .json file on your computer. Open loads one back in exactly as it was — use this to pick up a project again after weeks or months. Save reuses the last filename; Save As always asks for a new one.
Saved versions & Compare
"Save version" snapshots the current calculation into an in-app library (grouped by project) so you can revisit or compare several versions side by side, drag columns to reorder, and set any version as the baseline. This library is separate from Save/Open files.
Licensing
The app requires an activation key tied to your name and an expiry date. It stops working automatically once that period ends — re-activate with a new key from whoever issued it.
Settings
The ⚙ icon lets you change the accent color and overall app size — both remembered on this device.
Reports
Use the File menu's "Export & Analyze" to generate a PDF report or CSV of results, and comparison reports across saved versions.
